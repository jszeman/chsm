# Cgen documentation

Cgen is a straightforward state machine design GUI with language-independent code generation capabilities. Output files are created using Jinja2 templates, allowing users to define custom templates to support any programming language or specific state machine implementation.

The following documentation outlines the development process for creating such a custom template.
